Integritetspolicy

Senast uppdaterad: 12 oktober 2026

Bridge by Hjille kräver inget konto hos Hjille. Du kan spela lokalt på din enhet. Vissa onlinefunktioner använder Apples tjänster, till exempel Game Center, iCloud/CloudKit och APNs.

1. Vem tillhandahåller appen

Bridge by Hjille tillhandahålls av Eric Gille. Frågor om appen, integritet eller support kan skickas till support@hjille.se.

2. Lokalt och offline spel

Du kan spela Bridge by Hjille lokalt på din iPhone eller iPad utan att logga in i Game Center. Då sparas uppgifter som behövs för appens funktion lokalt på enheten, till exempel språkval, inställningar, lokalt spelarnamn, sparade spel, spelhändelser och lokal matchstatistik.

Lokalt sparade spel och inställningar skickas inte till Hjille bara för att du spelar offline. De kan däremot ingå i frivillig diagnostik om du själv har aktiverat diagnostikdelning.

3. Game Center, spelaridentitet och vänner

När du använder onlinefunktioner använder appen Apples Game Center för inloggning, spelaridentitet, vänlista, inbjudningar, turbaserade matcher, matchresultat och topplistor.

Appen kan behandla ditt Game Center-visningsnamn, Game Center-spelar-ID, vilka spelare som deltar i en match, vems tur det är, matchstatus och resultat. Dessa uppgifter behövs för att identifiera spelare, koppla spelare till sitsar, skicka turen vidare och visa matcher korrekt.

Om du väljer att bjuda in vänner kan appen begära åtkomst till din Game Center-vänlista. Vänlistan används för att visa valbara vänner och skapa en Game Center-inbjudan. Funktionen är frivillig och behövs bara för väninbjudningar.

Game Center drivs av Apple. Apples egna villkor och integritetspolicy gäller för Apples behandling av uppgifter i Game Center.

4. Onlinematcher och matchhistorik

När du spelar online kan matchens tillstånd och historik skickas via Game Center och/eller CloudKit. Det kan omfatta match-ID, deltagare, spelar-ID, visningsnamn, sitsfördelning, inställningar, givarnas information, bud, spelade kort, poäng, resultat och annan spelhistorik.

Uppgifterna används för att båda spelarna ska kunna spela samma match, återuppta en match, se resultat och hantera turbaserade händelser.

5. iCloud och CloudKit

För vissa onlinematcher använder Bridge by Hjille Apples CloudKit i iCloud för att synkronisera matchdata. Appen använder CloudKit-containern iCloud.hjillesoft.Bridge-by-Hjille.

CloudKit kan lagra matchmetadata, deltagaruppgifter, Game Center-match-ID, spelaridentifierare, visningsnamn, matchinställningar, antal givar, status, resultat per giv, poäng och spelhistorik. Frivillig diagnostik kan också laddas upp till CloudKit om du har aktiverat det.

CloudKit drivs av Apple. Data i appens CloudKit-container kan vara tillgänglig för utvecklaren eller utvecklarteamet för administration, felsökning och support. Den här policyn påstår inte att CloudKit-data endast är åtkomlig för utvecklaren.

6. Frivillig diagnostik

Diagnostikdelning är avstängd som standard. Om du aktiverar diagnostik i appens inställningar kan appen spara och ladda upp diagnostikdata till CloudKit för att hjälpa till att hitta och rätta fel.

Diagnostik kan innehålla appversion, buildnummer, iOS/iPadOS-version, enhetsmodell, enhetstyp, om appen körs i simulator, buildkonfiguration, felbeskrivningar, spelstate, de senaste spelhändelserna, DDS-anrop och teknisk information om AI-analys.

Om du stänger av diagnostik rensar appen väntande diagnostikfiler som ännu inte har laddats upp från enheten. Diagnostik som redan har laddats upp raderas inte automatiskt bara för att du stänger av diagnostikdelning.

7. Pushnotiser för matchuppdateringar

Appen kan registrera sig för tysta pushnotiser via Apple APNs/CloudKit. Syftet är att snabbare upptäcka när en onlinematch har ändrats. Appen är inte beroende av pushnotiser för att fungera, eftersom den även uppdaterar matchdata vid öppning, aktivering och synkronisering.

Appen lagrar inte någon APNs-token i egen kod enligt den implementation som har granskats.

8. Tredjepartstjänster

Bridge by Hjille använder Apples tjänster för distribution och onlinefunktioner, inklusive App Store, TestFlight, iOS/iPadOS, Game Center, iCloud, CloudKit och APNs. Apples egna villkor och integritetspolicy gäller för Apples behandling.

Appen använder inte externa annonstjänster, analys-SDK:er eller spårningsskript på den här webbplatsen.

9. Lagring, radering och supportärenden

Lokala uppgifter finns kvar på din enhet så länge appen eller de lokala sparade uppgifterna finns kvar. Att radera appen tar normalt bort appens lokala data från enheten.

Game Center-data hanteras av Apple. Du kan hantera Game Center och iCloud i iOS/iPadOS-inställningarna.

För CloudKit-matchdata och redan uppladdad diagnostik finns ingen bekräftad automatisk lagringsperiod i appens implementation. Om du vill fråga om, få hjälp med eller begära radering av uppgifter som kan vara kopplade till dig, kontakta support@hjille.se.

10. Dina val

  • Du kan spela lokalt utan Game Center.
  • Du väljer själv om du vill använda Game Center och onlinefunktioner.
  • Du väljer själv om du vill ge åtkomst till Game Center-vänlistan för inbjudningar.
  • Du kan slå av och på diagnostikdelning i appens inställningar.
  • Du kan kontakta support om du behöver hjälp med integritetsfrågor eller raderingsbegäranden.

11. Spårning, annonser och försäljning

Bridge by Hjille använder inte information för att spåra dig mellan appar eller webbplatser. Appen säljer inte användardata till tredje part och innehåller inga annonser enligt den implementation som har granskats.

12. Ändringar i policyn

Den här policyn kan uppdateras när appens funktioner, tekniska lösningar eller juridiska krav förändras. Den senaste versionen publiceras på den här sidan.

13. Kontakt

Frågor om Bridge by Hjille, support eller integritet kan skickas till support@hjille.se.
